# 中文使用手册

## 开始一次科研任务

1. 总览查看真实收录规模与最近更新。
2. 技能库输入中文用途或英文名称，组合学科、科研环节、已安装与已实测筛选。热度只代表仓库关注度；未知星数按未知显示。
3. 打开详情，阅读用途、原文、许可证、依赖及来源固定提交。缺少中文说明时保留原文；可以选择模型与预算，手动翻译公开用途，译文需复核。
4. 安装版本。全局安装适用于个人项目，也可在详情中指定某个项目。
5. 设置中保存自己的模型配置，付费模型配置价格来源。
6. 科研项目创建项目，上传 PDF、CSV、Excel、DOCX 或文本。原始同名文件不覆盖；新资料请换名。
7. 选择模型与已安装版本，填写具体任务与预算，开始运行。
8. 查看运行详情和下载成果。保留实际模型标识、固定技能版本、输入哈希、工具证据、生成代码、费用估算和错误。

报告默认生成 Markdown 与 DOCX。CSV、PNG、PDF 和其他科研文件由 Python 动作保存到 `/outputs`；容器中已包含常用数据分析、绘图及 PDF 生成库。扫描型 PDF 首版不包含 OCR，应先转换为可抽取文字的资料。正文读取最多前 50 页、最多 4 万字符，界面/工具记录会说明截断。

可从 `examples/analysis/sample.csv` 开始，任务示例：“读取 sample.csv，计算 value 的均值、样本标准差和有效样本数；说明缺失值处理；保存 CSV、PNG 和可复运行 Python 脚本。不要虚构执行结果。”该任务需要 Docker。

## 比较技能与模型

技能库或详情点击“加入比较”，支持同一技能新旧版本。比较中心选择四组公开基准之一：

| 基准 | 自动检查 | 人工复核 |
|---|---|---|
| 文献与引用 | 真实 Crossref DOI 工具证据，标题、年份与 DOI 一致 | 引用用途与语义 |
| 数据分析 | Python 成功执行，均值 3、样本标准差约 1.58113883、n=5 | 方法适用性与缺失值说明 |
| 统计绘图 | Python 执行、PNG 文件 | 图意、轴标签、可读性，评分达到 4/5 才算通过 |
| 科研写作 | 事实约束，不允许编造显著性 | 匿名样本评分，达到 4/5 才算通过 |

比较技能固定一个模型，加入无技能基线；比较模型固定一个技能版本。输入、参数、模型配置和代码镜像固定，默认每个候选三次。不同批次配置不合并排行。

先设置整个批次预算。失败计入结果；取消后剩余试验记为未运行。已发送模型请求可能仍产生费用。展示的人民币费用基于用户配置价格；缺少服务商用量时按预留保守记账。

未通过质量检查、未人工评分、样本少于三次时不能推荐替代。文字质量仍需要研究者判断；标签匿名不保证正文不会提示来源。平台首版没有自动模型裁判，避免把模型评分当作优胜证据。

## 替代、升级与回退

同一技能升级：先加入新旧版本比较，再在详情“版本与替换”切换。不同技能替代：打开新技能详情，选择“替代已安装技能”的旧技能，核对用途、依赖与比较结果后“确认替代”。新包检查成功后才切换；历史保存旧版本。

项目级选择只影响该项目；全局选择影响后续项目任务。运行中的任务继续使用启动时固定的版本。在更新中心找到已安装版本，点击回退。个人修改使用“导出”后编辑并重新导入 ZIP，生成独立本地命名空间。

## 更新来源

添加 GitHub `owner/repo`，点击立即扫描。精选列表本身未必包含 SKILL.md，需要添加列表中可追溯的真实仓库。扫描不会调用模型。公开快照更新可来自自己的 GitHub 月末 Actions，见 [部署指南](DEPLOYMENT.md)。

收录失败查看更新报告，旧版本继续保留。内容、依赖声明、许可证与来源删除分别报告；仅资源脚本内部的依赖变化可能体现为内容变更，自动扫描不做完整软件依赖推断。

## 隐私与费用

离线搜索不需要模型。运行任务会把任务描述和按工具读取的资料发送给所选模型服务商；本地 Ollama 的资料在本机处理。月末扫描只访问公开仓库，不上传个人资料。密钥与个人记录位于 `data/`，Git 忽略该目录。

取消、失败、超时不会抹除已有记录。模型费用与科研质量均需结合服务商账单及人工复核判断。

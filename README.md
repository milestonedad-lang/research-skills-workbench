# Research Skills Workbench

An AI workbench for scientific research, integrating agent skill discovery, reproducible workflows, controlled benchmarking, monthly catalog updates, and versioned skill replacement and rollback.

完整首版与中文部署指南位于 [feature/workbench-v0.1](https://github.com/milestonedad-lang/research-skills-workbench/tree/feature/workbench-v0.1)。检视测试与验收边界后合并到 main，以启用月末工作流。
